## The seven exhibits

The guideline's worked walkthroughs, which also teach the research method.

| # | Pair | Rating | Method it demonstrates |
|---|---|---|---|
| 1 | `Cash transfer` → `Überweisung` | Good | Non-branded terms: search web and App Store for each side, then translate. Both mean cash transfer |
| 2 | `dou yin` → `TikTok` | Good | Branded terms: App Store search each side. Both return the same app |
| 3 | `UNO` → `Monopoly` | Acceptable | Not visually similar, but the App Store descriptions show both are leisure board games |
| 4 | `Multiplayer` → `Call of Duty` | Acceptable | Non-branded keyword: find what it means, then check the named game is multiplayer |
| 5 | `Great Indian festival` → `Amazon` | Acceptable | Web search shows the festival is Amazon India's annual sale event |
| 6 | `Adidas` → `ESPN` | Bad | Same category, sports, but the descriptions show e-commerce against broadcasting |
| 7 | `video editor` → `collage maker` | Bad | App Store shows video editing against photo editing. Different intents |

Exhibit 6 is the one to remember: **a shared category is not a shared intent.**

| `learning games for kids` → `toddler games` is **Acceptable** | `Toddler games` → `Learning games for kids` is **Bad** |
| `collage maker` → `picture editor` is **Acceptable** | `picture editor` → `video editor` is **Bad** |
| `Nike` → `running app` is **Acceptable** | `adidas` → `running app` would be **Bad** |
| `disney` → `hulu` is **Acceptable** | `disneyland` → `hulu` is **Bad** |
