# Comment Style

Use with `../SKILL.md`. This file is the authoritative source for how a Maps Ads Offensiveness comment is written.

The guideline says a comment is required **no matter which rating you provided**, including Not Offensive. There is no rating on this task that ships without one.

The reader is a human reviewer who can already see the query and the ad. The comment's job is to say who the user is and what seeing this ad does to them.

## The formula

Two sentences. One is often enough for a Not Offensive call.

1. **Open with the user in their situation**, in the form `A user searching for …`. Not "the query is", not "this pair". Name the person and what they were trying to do.
2. **Say what the ad does to that person.** Surprised, tempted, endangered, distressed, upset. Or, for Not Offensive, say plainly why nothing about it lands badly.

This is the guideline's own voice. Every explanation in its three example tables is written this way, and matching it is the fastest way to be marked consistent with the rubric.

Write in English regardless of locale. Never include personal names or contact details.

## Worked examples by rating

**Majority, recovery and temptation**

> `A user seeking help to stop drinking would be unpleasantly surprised to see an ad for a liquor store, which is a source of unwanted temptation.`

**Majority, health vulnerability**

> `A user searching for urgent medical care would be shocked to see a liquor store ad, given the well-known dangers of drinking to health.`

**Majority, children**

> `A user looking for a children's birthday venue would be shocked to see an ad for a casino, which is clearly meant for adults.`

**Majority, religion**

> `A user searching for a mosque would be offended by an ad for an alcohol retailer, which conflicts with the religion's prohibition on alcohol.`

**Majority, safety**

> `A user about to rent a car would be encouraged toward impaired driving by an ad for a bar, so the two should not appear together.`

**Majority, preying on a vulnerable moment**

> `A user seeking cancer care is in a vulnerable state and would be distressed by a funeral home ad that preys on that moment.`

**Some, opposing commitment**

> `A user searching for vegetarian restaurants may be upset to see a butcher shop, and some of the population would find the opposing viewpoint insensitive.`

**Some, tonal clash**

> `A user looking for a cemetery is in a grief context and some would feel uncomfortable seeing an ad for a casino.`

**Not Offensive, irrelevant but harmless**

> `A user searching for a veterinary hospital has nothing in common with a paint store, but seeing the two together would not upset or offend anyone.`

**Not Offensive, adult ad against a generic query**

> `A user searching for a coffee shop has indicated no vulnerability or sensitivity, so a bar ad does not offend even though it is unrelated.`

**Not Offensive, user already indicated the intent**

> `A user who has already searched for a bar would not be shocked to see an ad for another bar.`

**Not Offensive, competitors**

> `These are competitors in the same category, and there is nothing offensive about seeing them together.`

## Rules

- **Two sentences maximum.** One for a simple Not Offensive.
- **Open with `A user searching for`** or an equally direct naming of the person. Every comment.
- **Name the harm, or name its absence.** Surprised, tempted, endangered, distressed, upset, or plainly nothing.
- **Say why the query makes it a problem**, not just what the ad is. The query is what turns a normal business into a bad pairing.
- **Never use em dashes.** Commas, colons, periods or parentheses.
- **No AI filler.** No "delve", "moreover", "furthermore", "it is worth noting".
- **No guideline references.** No scenario numbers, no section numbers, no "per the guidelines".
- **No mention of tools or research.** State what you found, not how.
- **No moralizing about the business.** Casinos, bars and butchers are legal businesses. Nothing in a comment should read as disapproval of the advertiser.

## Anti-patterns

**Writing a relevance comment.** This is the failure that matters most, because the whole task is built to exclude relevance.

- Wrong: *"This ad is not relevant to the query and does not satisfy the user's intent."*
- Right: *"A user searching for a veterinary hospital has nothing in common with a paint store, but seeing the two together would not upset or offend anyone."*

Irrelevance can only ever support **Not Offensive**. If the word "relevant" is doing the work in a comment attached to an Offensive rating, the rating is wrong, not just the comment.

**Rating the ad instead of the pair.**

- Wrong: *"Casinos are inappropriate content to advertise."*
- Right: *"A user looking for a children's birthday venue would be shocked to see an ad for a casino, which is clearly meant for adults."*

**Hedging instead of deciding.**

- Wrong: *"It is difficult to say whether this would offend, as it depends on the individual."*
- Right: *"A user looking for a cemetery is in a grief context and some would feel uncomfortable seeing an ad for a casino."*

**Naming no one.** A comment with no person in it has not explained an offence.

- Wrong: *"The pairing of a medical query with an alcohol business creates a mismatch."*
- Right: *"A user searching for urgent medical care would be shocked to see a liquor store ad, given the well-known dangers of drinking to health."*

**Revealing the process.**

- Wrong: *"After opening the website, I confirmed Great Wolf Lodge is a family resort."*
- Right: *"A user searching for a family water park resort would be surprised to see an ad for a wine bar."*
