# Worked Examples From The Guideline

Use with `../SKILL.md`. Every pair below is an official example from the Maps Ads Offensiveness guidelines (August 2026), with the guideline's own explanation condensed. Use them as precedent: find the pair whose shape matches yours, then apply the rule that decided it.

## Majority may find the pair Offensive

| Query | Result Ad | Why |
|---|---|---|
| `alcohol addiction treatment center` | Wiley's Liquor Store | Someone seeking help to quit drinking is unpleasantly surprised by a source of unwanted temptation. |
| `urgent care` | Wiley's Liquor Store | A medical search shown alcohol, given the well-known dangers of drinking to health. |
| `kids birthday party venue` | Empire City Casino | A venue clearly meant for adults against a search for children. |
| `mosque` | Total Wine & More | The ad conflicts with the religion's prohibition on alcohol. |
| `car rental near me` | The Tap Room (bar) | A driving-related search paired with an alcohol venue promotes impaired driving. |
| `cancer treatment center` | Restland Funeral Home | The user is in a vulnerable state and the ad preys on that moment. |
| `preschoool` | Voodoo Brewing Co. | Misspelled, but very likely a preschool. An alcohol ad against that is offensive. |

## Some may find the pair Offensive

| Query | Result Ad | Why |
|---|---|---|
| `vegetarian restaurants` | 3 Arrows Boutique Butcher | Opposing viewpoints, perceived as insensitive by some of the population. |
| `animal shelter` | Backwoods Hunting Outfitters | Someone looking to adopt or help animals may be upset by a hunting ad. |
| `cemetery` | Cherokee Casino | Someone in a death or grief context may feel uncomfortable seeing gambling and entertainment. |

## Not Offensive

| Query | Result Ad | Why |
|---|---|---|
| `Hotel` | Hyatt Regency Lake Tahoe Resort, Spa and Casino | A generic hotel query with no mismatch, vulnerability or unsafe-behavior element. |
| `McDonald's` | Burger King | Competitors, and nothing offensive about the pairing. |
| `veterinary hospital` | Sherwin-Williams Paint Store | Nothing in common and not relevant, but nothing upsetting either. |
| `bar near me` | The Tap Room (bar) | The user already indicated interest in a bar. |
| `Starbucks` | The Tap Room (bar) | Not relevant, since Starbucks serves no alcohol, but not offensive. |

## The contrasts worth memorizing

Each row is one hazard against two different queries. The hazard is constant; the rating is not. This is the whole task in six lines.

| Same ad, different query | | |
|---|---|---|
| A bar | `car rental near me` → **Majority** | `Starbucks` → **Not Offensive** |
| A liquor store | `urgent care` → **Majority** | a generic retail query → **Not Offensive** |
| A casino | `kids birthday party venue` → **Majority** | `Hotel` → **Not Offensive** |
| A casino | `cemetery` → **Some** | `bar near me` → **Not Offensive** |
| A butcher | `vegetarian restaurants` → **Some** | a generic food query → **Not Offensive** |
| A funeral home | `cancer treatment center` → **Majority** | `death valley` → **Some**, by the ambiguity rule |

If you find yourself rating an ad rather than a pair, come back and read this table again. Four of these six ads are Not Offensive somewhere on this page.
