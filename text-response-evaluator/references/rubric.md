# TELUS Text Response Evaluation Rubric

Use this reference when applying `telus - Text_Response_Evaluation.pdf`.

## Task Shape

Each task has a text-message transcript between two people. The evaluator must:

1. Summarize the transcript in 30 words or fewer.
2. Decide if the transcript passes or rejects.
3. If rejected, choose all rejection reasons that apply.
4. If passed, choose the best response to the final message.
5. Answer the multiple-choice question from the original transcript only.

## Summary Rules

- Identify the overall topic.
- Include more than one primary topic if needed.
- If the transcript has many unrelated topics or no clear topic, mention that.
- Use plain language.
- Do not exceed 30 words.
- Prefer a natural two-person style when it fits:
  - `[Name A] and [Name B] are talking about [topic]. [Name A] says/asks..., while [Name B]...`

Examples:

- `Chris and Alex are talking about the Egyptian pyramids. Chris claims aliens built them, while Alex argues that ancient Egyptians built them.`
- `Sailor and Captain are talking about whether to delay sailing because of a storm report. Sailor wants caution, while Captain thinks they can manage it.`

## Rejection Reasons

When reporting a rejection, include the exact evidence whenever possible. This is required for traceable issues:

- Spelling mistake: quote the misspelled word and correction.
- Unnecessary repetition: quote the repeated words.
- Contains emojis: mention that an emoji appears, and quote surrounding text if useful.
- Includes name of participant: quote the line or phrase that mentions the other speaker label.
- Conversation rhymes: quote the consecutive ending words.

### Spelling Mistake

Reject for any spelling mistake in American English.

- Rate spelling only.
- Ignore punctuation and grammar.
- Context matters: `dew` is wrong if it should mean `due`; `Your` is wrong if it should mean `You're`.
- Extra or missing letters count, such as `stilll`, `helllo`, or `paralllel`.

### Unnecessary Repetition

Reject if words repeat for no reason in the same sentence.

- Reject: `going to to Iceland`
- Reject: `a a lunch bag`
- Pass: `When I last saw it, it was...`
- Pass: `I know that that is not true`
- Pass repeated topic words when repetition makes sense.

### Contains Emojis

Reject if any emoji appears anywhere in the transcript.

### Offensive Language

Reject for swearing or offensive slang in American English, including offensive body-part slang.

### Includes Name Of Participant

Reject if one participant mentions the other participant's name or User ID.

- Reject: `Hi, Person A!`
- Reject if Rose says `Oh, Daisy` when Daisy is the other participant.
- Reject if one participant uses the other participant's visible speaker label, even when that label is a role or title.
- Reject: `Thanks, Captain.` when the two speaker labels are `Sailor` and `Captain`.
- Reject: `Hey Me` when the two speaker labels are `PersonA` and `Me`.
- Pass if someone names a third person who is not part of the conversation.

Hard check:

1. List the two exact speaker labels before grading.
2. Search each person's messages for the other person's exact label/User ID.
3. If found, select `Includes Name of Participant`.

### Incoherent Or Not Human

Reject if the conversation is hard to follow, robotic, unnatural, or seems generated.

Reject for:

- Repeating the same answer over and over.
- Abrupt unrelated topic shifts.
- Multiple overlapping conversations.
- Extremely formal or unnatural wording for texting.
- Lines that do not respond naturally to previous lines.

Pass if:

- The topic changes naturally.
- The conversation has more than one topic but remains fluid.

### Conversation Could Not Happen Over Text

Reject if the conversation assumes the texters can see, hear, touch, or physically interact with each other.

Reject for:

- Stage directions like `[1 hour later at the cafe]`.
- Ellipses used as scene/time/location transitions.
- In-person directions like `Not there, more to the left`.
- Comments on current appearance like `Did you get your hair cut? It looks great!`
- Handing objects, seeing hidden objects, or telling someone to close/open eyes during the same text scene.

Pass if someone talks about something text-appropriate, such as `I just got my hair cut` and the other says `Can't wait to see it`.

### Conversation Rhymes

Reject if the last word or words of one message rhyme with the last word or words of the next message.

- The rhyming words must be different.
- The rhyming words must end consecutive messages.
- Same repeated ending word is not considered rhyme.

## Response Selection Rules

Pick the best response to the transcript's final message.

Good responses:

- Answer the last message directly.
- Match tone and context.
- Come from the correct speaker.
- Sound casual and natural.
- Avoid all rejection issues.

Bad responses:

- Repeat the last message or repeat something already said.
- Change topic.
- Use placeholders like `[topic]`.
- Assume the people are together in person.
- Contain spelling mistakes, emojis, offensive language, unnecessary repetition, rhymes, or impossible text actions.

## Multiple-Choice Rule

The question refers only to the original conversation. Do not use the response you selected as evidence for the MCQ.

Read the question wording literally. Similar-looking questions can require different answers:

- `Who sent the last text?` = identify the last speaker.
- `Who did not send the last text?` = identify the other speaker, unless both/none apply.
- `Who did not ask any questions?` = check every message from each participant before answering.
- If both participants did the action, choose `Both` when that is the option.
- If neither participant fits, choose `None of them` when that is the option.
