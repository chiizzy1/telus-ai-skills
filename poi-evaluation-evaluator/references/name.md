# Name (§5)

Three bands only — `Correct`, `Partially Correct`, `Incorrect`. **There is no
`Can't Verify` on Name.** You must commit.

| Option | Definition |
|---|---|
| **Correct** | The expected POI name, or a defined variation of it |
| **Partially Correct** | Minor misspellings, alterations, or a name implying a different level of service or kind of business |
| **Incorrect** | Major misspellings, slang, unofficial nicknames, or confusing and not easily identified — including a name in the wrong language for the locale, or mixed scripts |

## The governing principle

> **Every name a specific business location uses to refer to itself is `Correct`.**

Look for it on the chain locator page, the About section, claimed social pages, and
signage shown on official sites or social pages. Only when official sources are
unavailable: signage in recent street imagery or on review pages, recent primary
publications, and official menus in user-submitted or scanned photos.

> **Go to the operator's own page before directory consensus.** A live task produced a
> wrong `Partially Correct` because three directories agreed on a variant while the
> business's own Facebook used the form that was actually listed. Directories agreeing
> is not evidence about what a business calls itself.

## Error components — tick all that contributed

On any demotion, a checkbox list appears. The pairs below are the ones that get
confused; the guideline draws each line explicitly.

| Component | Use it when | Not when |
|---|---|---|
| **Acronym/Abbreviation** | The letters or words themselves are wrong — an acronym where the full name belongs, the full name where an acronym belongs, or the wrong initials (`IEA` for `IKEA`) | The letters are right but mis-cased (`Ymca`) → **Capitalization**. Colloquial slang (`Maccas`, `Starbies`) → **Other** |
| **Capitalization** | Wrong case against a specific house style (`GAMESTOP` for `GameStop`); an acronym correctly lettered but wrongly cased | `Incorrect` **only if the case error itself causes misidentification** — otherwise `Partially Correct` |
| **Extra Words** | Added words, including a generic descriptor appended to an intact official name (`Cheesecake Factory Restaurant`) | The generic term *replaces* or dominates the real name → **Category as Name** |
| **Category as Name** | A generic descriptor stands in for, or overshadows, the official name | Only acceptable as `Correct` when no official name can be confirmed at all |
| **Missing Words** | An omitted word materially impairs identification (`Cheesecake` for `Cheesecake Factory`) | Optional location modifiers are not required |
| **Location Modifier** | A modifier is added, omitted or misspelled. A misspelled modifier is `Partially Correct` | A modifier identifying a specific campus (`University of California, Irvine`) **is** required |
| **Punctuation** | A corporate designation is confirmed part of the name and only its formatting is wrong (a missing period) | The designation does not belong at all → **Holding Name/Corporate Structure**. Never tick both for one error |
| **Holding Name/Corporate Structure** | A parent or holding company name, or an `Inc./LLC/Ltd.` that the location does not use. Recognisably related (`Nordstrom, Inc.`) → `Partially Correct`; unrelated (`JAB Holding Company` for `Peet's Coffee`) → `Incorrect` | |
| **Service-Level Mismatch** | The name implies a different tier or format (`Holiday Inn` vs `Holiday Inn Express`). **Always `Partially Correct`**, in either direction | |
| **Misspelling** | Minor (one transposed or missing letter) or moderate (two or more errors, still identifiable) → `Partially Correct`. Severe — produces a different word or makes the POI unrecognisable → `Incorrect`. Pluralisation errors are minor | |
| **Article** | A definite/indefinite article wrongly added or omitted. Omitting one a business uses may still be `Correct` if widely recognised without it; **adding** one it does not use is `Partially Correct` | |
| **Diacritic/Special Character** | Missing or wrong accents, or brand characters (`&` in H&M, the reversed `Я` in Toys "R" Us) | Not flagged when the form without the character is itself a verified name |
| **Synonyms** | A near-equivalent word substituted for the official one (`local police` for `municipal police`) | |
| **Language/Script Issue** | Unexpected language or mixed scripts for the locale | International brand names in their original language are generally `Correct` |
| **Market Specific Issue** | A locale-specific convention error — honorifics, word order, expected structures — that fits nothing else | |
| **Other** | Slang nicknames (`Mickey D's`, `Wally World`), duplicated elements (`uhaul uhaul`), unrelated businesses combined in one listing | |

## Both forms correct

Where a business uses either version, both are `Correct`: exclamation marks
(`Yahoo!` / `Yahoo`), question marks (`GUESS?` / `Guess`), and hyphens in compound
brands (`7-Eleven` / `7 Eleven`).
