# Phone (§8)

| Option | Meaning |
|---|---|
| **Correct** | Verified against official and/or authoritative sources |
| **OK Without** | No number listed, and research shows the business has none |
| **Missing** | No number listed, but research shows one exists |
| **Incorrect** | The listed number is not the business's, and another number should be shown |
| **Can't Verify** | Cannot be verified using an **official** online source |

## Rules

- **Formatting never demotes.** A correct number in an odd format stays `Correct`.
- **Any one official number is enough.** Where a POI has several, listing any correct
  official number is `Correct`.
- **A fax number is `Incorrect`.**
- **Unattended POIs** — transit stops, EV chargers, bike racks — are `OK Without` when
  no number is listed. If one *is* listed, confirm it through official or authoritative
  sources.
- **Management offices count.** Where a park, bridge, metro station or monument is
  managed by an office with a number, treat that as the official number. If the listing
  lacks it, note in the comment that the number found belongs to the management office.
- **When no number is listed**, search for one before answering. Then rate `Incorrect`
  or `Missing` and paste the number into the comment box.

`OK Without` asserts the business *has* no phone number. That is a research finding,
not a default for a search you did not run.
